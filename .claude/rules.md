# pixelforge-demos rules

Follow root `AGENTS.md`.

- Tasks: `eval/tasks/<task_id>/` (`task.md` + `eval.md`)
- Scratch: `eval/runs/` (do not commit)
- Curated: `output/<task_id>/<version>/<harness>/`
- Packs: `demos/<slug>/` · Pages: `site/`
- No `examples/` in pixelforge-ai · CDN for large media · `aestheticApproval: false` by default
