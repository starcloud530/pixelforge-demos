# 指标 Metrics

商业上要回答的是：修到可交付要多久，盲评里是否更常被选中，特征还在不在，有没有严重缺陷。PSNR、SSIM、LPIPS 只辅助。自动结构探针也只辅助。

人工字段在没有记录时必须是 JSON `null`，状态是 `pending_human`。校验脚本会拒绝任何填上的分数。

## 汇总公式

记一次盲评比较有胜、负、平。平局算一半。

`盲评得分 = (胜次数 + 0.5 × 平局次数) / 比较次数`

比较次数是这个方法实际参与、并且票已填写的配对数。没有票时得分是 `null`，不是 0。

人工特征保留率是各已评行的清单保留率的算术平均。未评行不进入分母。

人工严重缺陷率是已评行里至少有一条 S1–S5 的比例。

精修时间报告已填写日志的中位、最小、最大。中位的取法与延迟相同：排序后取靠后的中间项。少于 1 条日志时三个值都是 `null`。

比例的不确定范围用 Wilson 区间，`z = 1.959963984540054`（约 95%）。没有样本时区间是 `null`。v1 自动探针上的 Wilson 区间只描述这 12 行里的探针计数，不是未来 100–200 个角色的聚类标准误，也不能写成那一套角色集的置信区间。

## 自动结构探针

参照不是中心采样公式，而是每个目标格对应的源矩形（box）。源宽高能被目标整除时，格子 `(tx, ty)` 的源矩形是

`x ∈ [tx × src_w / dst_w, (tx + 1) × src_w / dst_w)`，y 同理。

矩形内每个源像素的 alpha 都是 255，叫实心格。都是 0，叫空格。其余叫部分格，不参加实心/空心一致率。

输出格不透明，当且仅当索引不是 0。协议要求索引 0 的 alpha 为 0。

| 探针 | 通过 |
| --- | --- |
| 实心/空心一致 | 一致格数 / 实心或空心格数 ≥ 0.99 |
| 孔或空隙 | 声明点所在目标格是透明。声明点所在的源矩形必须整格 alpha 为 0，否则是固件错误，不是转换得分 |
| 细线 | 沿中心线每半个目标格取一个样本。样本格，以及 Chebyshev 距离 ≤ 1 的邻格，只有源矩形里真有这条线的像素才算数：像素中心到线段的距离 ≤ 该线的 `reach`（笔划半宽，跟几何一起写死）。这些格子里有不透明输出，算命中。命中率 ≥ 0.5 为通过。旁边另一块色块不算这条线还在 |

`feature_retention_auto` 是该行通过的探针数除以探针数。实心/空心探针每行都有。孔、空隙、细线按清单另计。权重相同，不按固件调权重。

自动严重旗标：

| 旗标 | 条件 |
| --- | --- |
| S1 | 实心/空心一致率 < 0.90 |
| S2 | 某条声明细线的命中率是 0 |
| S3 | 至少有一个整格透明的源矩形，输出却不透明 |
| S5 | 某个声明的孔或空隙格不透明 |

没有自动 S4。命中率在 0 和 0.5 之间算探针未通过，但不是 S2。

这些阈值写在跑基线之前，不按中心采样的结果改。细线可以被中心采样整段丢掉；丢掉就记 S2，不把线挪到采样中心上。

## 辅助图像指标

先把源图每个像素按直线 alpha 铺到 `#808080` 上，再对目标格的源矩形做平均，得到参照 RGB。输出索引同样铺到这个灰色上。两边都含背景，所以透明区是否被填色会进入误差。

PSNR 是这三通道的峰值信噪比，峰值 255。均方误差为 0 时 `psnr_box` 记 `null`，`psnr_box_exact` 为真，不记成一个很大的数。已经落在整数格上的像素图，盒式平均和中心采样可能完全一致，这时辅助误差没有信息，特征仍看探针和人工清单。

SSIM 对三个通道分别计算再取平均。窗口 11，σ = 1.5 的可分离高斯，只在完整窗口落在图内的位置上计算。`K1 = 0.01`，`K2 = 0.03`，`L = 255`。这是本基准自己的定义，用来重复，不声称与某一个图像库的实现逐位相同。

LPIPS 本轮不计算。`lpips` 是 `null`，`lpips_status` 是 `not_computed`。不要填一个看起来合理的小数。

PSNR 和 SSIM 比较的是「索引结果」和「盒式滤波预览」，不是和一张人工像素稿比。硬边索引图会比平滑预览吃亏。它们不能单独决定方法好坏。

## 延迟

每个格子 3 次进程墙钟，记录最小、中位、最大，单位毫秒。汇总里的最小是各行最小的最小，最大是各行最大的最大，中位是各行中位的中位。范围只覆盖这三次观测。

## 色数

`opaque_colors` 是调色板里 alpha ≥ 128 的项数。`palette_colors` 是 `paletteReport.paletteColors`。两者都 ≤ 16 时 `palette_within_budget` 为真。平方 RGB 误差用报告里的 `maxDistance` 和 `totalDistance`，不另定义距离。

## 记录状态

| 状态 | 含义 |
| --- | --- |
| `pending_human` | 需要人填，现在为空 |
| `not_applicable_local_cli` | 本机 CLI，没有外部费用 |
| `not_computed` | 协议允许的指标，本轮没有运行 |

空着是完成状态的一部分。填上未观测的数字，校验失败。
